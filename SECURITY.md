# Security policy

AgentFence v0.1 is supported locally. Do not place credentials, raw reports, private paths, or exploit payloads in public issues. No private reporting route has been configured; establish one before public publication. Scanner reports are static observations, not incident verdicts.

If you discover a suspected defect, retain only the minimum synthetic reproduction
needed to explain it and avoid publishing scanned configuration, secret values,
machine paths, or an exploit chain. There is intentionally no claimed response SLA
or security inbox until a project owner supplies one. Supported scope is the local
v0.1 source/package on Node 24; unconfigured publication and unsupported runtime
versions are not a promise of support.
