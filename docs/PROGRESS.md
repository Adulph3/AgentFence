# Progress

## v0.1 local implementation — complete

The eight reviewed FIX-FIRST groups are now addressed: production stream/exit handling; scan-wide budgets and filesystem containment; analyzer semantics; discovery and workspace association; substantive catalog obligations plus explicit `network-deny` compound suppression; bounded model and schema limits; doctor behavior; and MIT package metadata with the Windows ACL contract. The scanner remains offline, non-executing, read-only by default, and raw-safe at its report boundary.

The M6/M7 integration normalizes bounded vendor MCP facts for Codex, Claude Code, Cursor, Kiro, VS Code, and generic MCP; handles Codex `env`, `env_vars`, headers, and bearer environment references without emitting values; classifies transport, launcher, selector, dynamic construction, numeric endpoint class, recognized filesystem roots, and enabled applicability; and keeps valid sibling entities when another entity is malformed. Project and opt-in user discovery use a fixed allowlist, injected home service for tests, bounded Markdown-only user traversal, opaque source/principal identifiers, and no home crawl. A user `.claude.json` selects only top-level MCP plus the one `projects` record keyed by the canonical explicit root; auth/history/nonmatching projects never enter facts, IDs, or output.

The worker boundary now returns analysis DTOs only and validates bounded, printable safe output before parent acceptance. Shell analysis is a bounded non-executing tokenizer (8,192 characters, 2,048 tokens, nesting 16). The compiled fixed rule registry owns catalog title/version/category/default severity/remediation/references/milestone and coverage identifiers; constructors verify category and cannot accept caller-owned public rule text. An independent trusted manifest resolves every registry positive/negative/adversarial/redaction ID to a named executable assertion; build and package checks fail if the mapping is missing. The catalog tests cover every `AF-SECRET`, `AF-SHELL`, `AF-SUPPLY`, `AF-MCP`, `AF-NET`, `AF-PERM`, `AF-FS`, `AF-PROMPT`, `AF-UNICODE`, and `AF-COMBO` rule family, plus negated/fenced and ordinary Arabic cases. Score grouping is structural/value-independent; same-principal compounds require shell, network, and sensitive-environment capabilities.

Fresh Sol review #6 returned FIX-FIRST for seven concrete local cases, all now remediated: Unicode U+202C is detected with safe coordinate identity; valid Cursor/Kiro hook siblings survive a malformed peer; public per-source byte limits apply before bounded source preprocessing and strict projection; interrupted destination output closes before acknowledgement, makes a backpressured acknowledgement signal-aware, and uses an identity-bound receipt for cleanup; failed acquisition sources retain unique ordinals; multi-target `rm` classification keeps the strongest target risk; and Claude strictly validates `defaultMode` and `disabledMcpServers`. Direct argv, shell payload, hook, package-option, filesystem-root, and vendor enable/approval semantics retain dedicated regressions. Terminal findings sort by numeric coordinates, and a non-public injected CLI runner proves supported-runtime exit, interruption, and output-failure behavior without exposing a runtime bypass. To resolve earlier post-suite benchmark failures, traversal collects metadata with fixed bounded lstat concurrency while preserving lexical ordering and all link/device/cross-device checks.

Schemas are strict Draft 2020-12 documents for scan, failure, and doctor envelopes with nested `additionalProperties:false`. JSON output is bounded to 16 MiB; terminal rendering orders severity and applies color only on TTY without `NO_COLOR`. Doctor reports carry the fixed six-adapter support metadata and fail closed on unsupported runtime or in-memory self-test failure. Package metadata is explicitly MIT, lock-root metadata agrees, and the package checker requires the fixed release allowlist including `LICENSE`. POSIX `--output` is mode 0600; on Windows confidentiality depends on the selected parent directory's inherited ACL, which local lexical/mocked tests do not validate.
